# Gregory Jay

Writer and developer, founder of [Face Dragons](https://facedragons.com). I build games, apps and tools for things I actually do: learning Tibetan, training, playing games with friends, and keeping a large media library in order.

Godot · Blender + Python · Three.js · Kotlin + Jetpack Compose · Swift · C++ · Node · Python · SQLite · LLM tooling
